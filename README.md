# BrieflyAI

BrieflyAI is a lightweight summarization tool designed to turn long text into clear, concise summaries. Whether you're processing articles, research papers, notes, or transcripts, BrieflyAI helps you extract the essential points quickly.

- Fast Summaries – Generate short, accurate summaries in seconds.
- Easy to Use – Simple interface and clean workflow.
- Offline Friendly – Works without internet (if configured with local models).
- Flexible Input – Supports long-form text, URLs (if enabled), and copy–paste content.

## Tech Stack

- React
- Tailwind / SCSS (depending on your setup)
- Transformer JS
